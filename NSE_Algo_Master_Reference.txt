2. WHY PYTHON + ML (NOT NO-CODE)
────────────────────────────────────────────────────────────────────────────────
No-Code platforms (Zerodha Streak, AlgoTest):
  - Simple rule-based strategies only
  - 2 million+ users → same strategies → edge dies fast
  - No ML/AI integration
  - No custom indicators
  - Backtesting is surface level
  - Results ceiling: LOW (2–5% monthly, edge dies in 3–6 months)
Python + ML:
  - Unlimited strategy complexity
  - XGBoost/LSTM ML signal generation
  - Custom indicators + live optimization
  - Kelly criterion position sizing
  - Regime detection (trending/ranging/volatile)
  - Multi-factor alpha combining
  - Results ceiling: HIGH (8–20%+ monthly, sustainable with recalibration)
Key insight: No-code = commoditized strategies = no edge
             Python + ML = unique strategies no one else has

14. KEY CONCEPTS
────────────────────────────────────────────────────────────────────────────────
ALPHA DECAY:
  As a strategy becomes known, other algos trade against it.
  Signal → more traders use it → edge shrinks → strategy underperforms.
  Solution: Pipeline of strategies always being tested in parallel.
REGIME DETECTION:
  Markets alternate between Trending, Ranging, and High-Volatility states.
  Momentum strategy works in Trending, fails in Ranging.
  Mean Reversion works in Ranging, fails in Trending.
  HMM auto-detects the regime → Layer 4 auto-switches strategy.
KELLY CRITERION:
  Optimal position size = (Win rate - (1-Win rate)/Reward:Risk) × Capital
  Use half-Kelly for safety: multiply result by 0.5
WALK-FORWARD VALIDATION:
  Train on months 1–12 → test on month 13
  Train on months 2–13 → test on month 14
  Repeat → gives realistic out-of-sample performance estimate
  Prevents overfitting to historical data
SHARPE RATIO:
  > 1.5 = good   > 2.0 = excellent
  Formula: (Strategy return - Risk free rate) / Strategy std deviation
  Use annualised Sharpe for comparison
DRAWDOWN:
  Max Drawdown = (Peak value - Trough value) / Peak value
  Keep max DD < 10% before going live
  If DD hits 5% intraday → pause for the day

16-A. EVENT-DRIVEN ARCHITECTURE (IMPROVEMENT #1)
────────────────────────────────────────────────────────────────────────────────
UPGRADE FROM: Loop-based sequential execution
UPGRADE TO:   Event-driven async pipeline
Event flow:
  MARKET_DATA_EVENT
       ↓
  FEATURE_EVENT
       ↓
  SIGNAL_EVENT
       ↓
  RISK_EVENT
       ↓
  ORDER_EVENT
       ↓
  FILL_EVENT
       ↓
  PORTFOLIO_UPDATE_EVENT
Benefits:
  - Each layer reacts only when its input event fires
  - Full session replay for debugging (pass events through same pipeline)
  - Deterministic backtests (same events = same result every time)
  - Broker switching = swap only the ORDER_EVENT handler
  - Multi-strategy: multiple signal handlers subscribe to FEATURE_EVENT
  - Paper/live parity: same pipeline, different ORDER_EVENT executor
Implementation:
  Start with: asyncio + Redis Pub/Sub (lightweight, no new infra)
  Scale to:   Kafka / NATS (later, when multi-strategy at scale)
Recommended stack:
  asyncio          — non-blocking event loop, already in Python stdlib
  redis (aioredis) — Pub/Sub message bus between layers
  pydantic         — typed event schemas (validate every event payload)
Install: pip install redis aioredis pydantic

16-B. PORTFOLIO ENGINE (IMPROVEMENT #2)
────────────────────────────────────────────────────────────────────────────────
Add centralized portfolio state tracking alongside the existing risk layer.
Track at all times:
  - Net long/short exposure (₹ and % of capital)
  - Sector concentration (no single sector > 30%)
  - Beta-normalized exposure (portfolio beta vs Nifty)

16-C. OVERFITTING PREVENTION (IMPROVEMENT #3) — CRITICAL
────────────────────────────────────────────────────────────────────────────────
This is the #1 reason ML algo strategies fail. Add all three layers:
A. PURGED K-FOLD CROSS VALIDATION
  Standard KFold leaks future information in financial time series.
  PurgedKFold removes overlapping observations + adds embargo period.
  Why critical:
    - Standard CV on financial data gives falsely optimistic Sharpe
    - Purged CV is the institutional-grade standard (Lopez de Prado, 2017)
    - Research (2025) confirms CPCV shows superiority in mitigating overfitting
  Library: mlfinlab
  Install: pip install mlfinlab
  Classes to use:
    - PurgedKFold         → purged cross validation
    - ml_get_train_times  → compute embargo periods
B. FEATURE STABILITY TESTING
  Track over time:
    - Feature importance drift (SHAP values shifting week-on-week)
    - PSI — Population Stability Index
    - KS test (Kolmogorov-Smirnov) on feature distributions
  PSI thresholds:
    PSI < 0.10 → Feature is stable
    PSI 0.10–0.25 → Moderate change, investigate
    PSI > 0.25 → Feature regime change detected — retrain model
  Action: If PSI > 0.25 on 3+ features → force immediate retraining
C. DEFLATED SHARPE RATIO (DSR)
  Problem: If you test 100 strategy variants, one will look good by luck.
  Solution: Deflated Sharpe Ratio corrects for multiple testing bias.
  Formula accounts for:
    - Number of backtests run
    - Non-normality of returns
    - Serial correlation in returns
  Rule: Only go live if Deflated Sharpe Ratio > 1.0
        (not just raw Sharpe > 1.5)
  Library: mlfinlab (DSR implementation included)

16-J. INDIA VIX REGIME LABELING (IMPROVEMENT #14) — NSE CRITICAL
────────────────────────────────────────────────────────────────────────────────
India VIX is NSE's own volatility fear gauge (launched 2008).
Derived from Nifty 50 OTM options order book — 30-day expected volatility.
How to interpret:
  VIX < 12       → Very low vol / complacency → mean reversion strategies
  VIX 12–15      → Normal regime → momentum strategies
  VIX 15–20      → Elevated uncertainty → reduce size
  VIX 20–25      → High vol → options premium selling opportunities
  VIX > 25       → Panic / event risk → flatten aggressive positions
  VIX > 30       → Extreme fear (e.g. April 7, 2025 spike +50%) → halt
Six NSE-specific regime labels (add to existing HMM regime detector):
  LOW_VOL        → VIX < 12, ADX < 20
  TRENDING       → VIX 12–18, ADX > 25
  MEAN_REVERTING → VIX 12–18, ADX < 20
  PANIC          → VIX > 25, sudden spike
  EXPIRY         → Last Thursday of month (options expiry week)
  EVENT_DRIVEN   → RBI policy day, budget day, US Fed day
Expiry regime is especially important:
  - Gamma exposure spikes dramatically on expiry day
  - Options prices collapse at 3:30 PM (time decay)
